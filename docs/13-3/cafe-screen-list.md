# モバイルオーダーアプリ 画面一覧

| ID | 画面名 | 役割 | 主な利用者 |
|:---|:-------|:-----|:-----------|
| SC-01 | メニュー画面 | 本日のメニュー一覧を表示し、注文する商品と個数を選ぶ（最初に開く画面） | お客さま |
| SC-02 | カート画面 | 注文する商品の個数とその合計金額を表示する | お客さま |
| SC-03 | 支払い画面 | 外部決済サービスにて支払いを依頼し、その結果を受け取る | お客さま |
| SC-04 | 注文完了画面 | 注文を受け付けたことと、注文番号を知らせる | お客さま |
| SC-05 | 注文状況画面 | 注文した内容が店側に届いているかの確認画面。注文の取消も行うことができる | お客さま |
| SC-06 | 注文一覧画面 | 受け渡されていない注文番号一覧が表示されている（最初に開く画面） | 店員 |
| SC-07 | 注文詳細画面 | 注文された詳細が表示されており、受け渡し済みにすると注文一覧に遷移する | 店員 |
