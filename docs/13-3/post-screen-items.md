# 画面項目定義

| 項目名 | 種類 | 必須 | 内容 |
|:---|:-------|:-----|:-----------|
| 画面見出し | 表示 | - | 「投稿編集」 |
| タイトル | 入力（1行） | 必須 | 記事のタイトル。開いたときには今のタイトルが入っている。 |
| カテゴリ | 選択 | 必須 | 登録されているカテゴリから1つ。開いたときには今の値カテゴリが入っている。 |
| 本文 | 入力（複数行） | 必須 | 記事の内容。開いたときには今の本文が入っている。 |
| 更新 | ボタン | - | 押すと記事の内容が更新され、投稿一覧に遷移する |
| キャンセルリンク | リンク | - | 押すと記事の内容はそのままで、投稿一覧に遷移する |
