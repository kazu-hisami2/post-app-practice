# 画面項目定義

| 項目名 | 種類 | 必須 | 内容 |
|:---|:-------|:-----|:-----------|
| 画面見出し | 表示 | - | 「本日のメニュー」 |
| 区分の見出し | 表示 | - | 「ドリンク」、「フード」 |
| 商品名 | 表示 | - | 商品の名前 |
| 値段 | 表示 | - | 商品の値段 |
| 短い説明 | 表示 | - | 商品の短い説明 |
| 売切の表示 | 表示 | - | 商品の在庫がないときに表示される |
| 個数 | 選択 | 必須 | 商品を注文する個数。売り切れの商品では選択できない |
| カートに進む | ボタン | - | 押すとカート画面へ遷移する。売り切れの商品では押せない |
| 注文状況を見る | リンク | - | 押すと注文状況画面へ遷移する |
