## APIエンドポイント一覧

| ID | メソッド | エンドポイント | 何をするか | 認証 |
|:---|:---|:---|:---|:---|
| API-01 | GET | api/posts | 投稿の一覧取得 | 必要 |
| API-02 | GET | api/posts/{post} | 投稿の1件を取得 | 必要 |
| API-03 | PUT | api/posts/{post} | 投稿の1件を更新 | 必要 |
| API-04 | DELETE | api/posts/{post} | 投稿の1件を削除 | 必要 |

#### API-03: 投稿1件を書き換える

- **メソッドとエンドポイント**: PUT /api/posts/{id}
- **認証**: 必要
- **送るもの**: URLに投稿の番号。本文で、タイトル（必須・255文字以内）と、本文（必須）と、カテゴリの番号（必須・登録済みのカテゴリのもの）
- **返すもの（うまくいったとき）**: 200。書き換えたあとの投稿1件（投稿の番号・タイトル・本文・カテゴリの番号・投稿者の番号・登録日時・更新日時）
- **返すもの（うまくいかなかったとき）**: 401（ログインしていないとき）／403（自分の投稿ではないとき）／404（その投稿が見つからないとき）／422（送ったものに不備があるとき）
